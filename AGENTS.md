# InterviewAce project instructions

The official project name is **InterviewAce**. Use exactly that spelling in user-facing text, README files, documentation, HTML metadata, screenshots, GitHub descriptions and release information. Do not add a product version suffix or separate the words.

Keep existing internal identifiers, database names, API routes, storage keys and repository URLs stable unless a task explicitly requires a migration. Lowercase npm package identifiers are technical identifiers; their descriptions use InterviewAce.
